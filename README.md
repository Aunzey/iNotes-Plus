# iNotes-Plus

> Gridea-Pro iNotes 主题升级版

本主题基于 [Gridea-Pro/gridea-pro-themes · themes/inotes](https://github.com/Gridea-Pro/gridea-pro-themes/tree/main/themes/inotes) 改造。

## 信息

| 字段 | 值 |
|---|---|
| 目录名 | `iNotes-Plus` |
| 版本 | `1.1.5` |
| 模板引擎 | `go` |

## 特性

相对原版 1.0.0 的增量：

- **亮/暗双主题**：页面右上角切换按钮，默认跟随系统，手动选择后通过 localStorage 记住
- **闪念页**（`/memos`）：热力图 + 闪念列表 + 分页；正文中的 `#标签` 自动隐藏（标签由闪念标签区单独展示）
- **瀑布流照片页**（`templates/photos.html`）：正文里的图片自动重排为瀑布流，点击打开灯箱查看大图
- **分类页**：单分类页 `category.html` + 分类列表 `categories.html`，与标签体系对称
- **文章上一篇/下一篇导航**：文章页底部左右对称展示前后篇，无邻居时显示占位（「没有上一篇了/没有下一篇了」）；在列表中隐藏的文章不显示导航
- **列表摘要**：首页/列表文章从正文去除 Markdown 标记后截取 120 字符纯文本摘要，不依赖文章「摘要」字段是否填写
- **自定义内容支持 HTML**：站点描述、底部信息经 `safeHTML` 渲染，可填写标题、链接等 HTML
- 文章列表与文章页新增分类展示；Disqus 评论主题跟随暗色模式

## 照片页（瀑布流）

主题自带瀑布流照片页模板 `templates/photos.html`，不依赖任何插件或外部库。

1. 在 Gridea Pro 里新建一篇文章，**URL（文件名）填 `photos`**
   - 不希望它出现在文章列表里，就在文章设置中打开「列表中隐藏」
2. 在正文里按顺序插入图片，推荐 Markdown 写法：`![图注](/post-images/xxx.jpg)`
   - `alt` 文字作为图注：默认隐藏，**鼠标悬停在照片上才浮出**（触屏设备常显）
   - 正文里其余文字会显示在照片墙上方
3. 在「菜单」里加一项：名称「照片」，链接填 `/post/photos`（按你的文章 URL 格式填写）
4. 预览即可看到瀑布流：手机 2 列 / 宽屏 3 列；点击图片打开灯箱看大图并显示 EXIF，
   支持 `←` `→` 翻图、`Esc` 关闭

### EXIF 的限制（重要）

灯箱里的相机型号、焦距、光圈、快门、ISO、拍摄时间，是页面在前端 `fetch` 图片后自己解析
JPEG 的 EXIF 段得到的。受浏览器安全策略限制，**必须同时满足两个条件**：

| 条件 | 说明 |
|---|---|
| 图片与页面**同源** | 放在站内（如 `/post-images/xxx.jpg`）才读得到；走图床或 Gridea Pro 的 CDN 加速时，若对方没返回 CORS 头，会被浏览器拦下 |
| 图片本身带 EXIF | 相机直出的 JPEG 一般都有；截图 PNG、社交软件转存的图片通常已被抹掉 |

读不到时灯箱会给出明确提示（「EXIF 不可用…」或「这张图片没有可用的 EXIF 信息」），不会静默失败。

实现说明：

- 样式、灯箱与脚本都定义在 `templates/includes/photo-masonry.html`（`photo-masonry` / `photo-masonry-style`）
- 卡片沿用主题文章图片的视觉语言：2px 圆角、`0 0 30px` 晕影（暗色为 `rgba(0, 0, 0, .7)`）、
  悬停放大 `scale(1.0082)`、600px 断点，以及 `#f8f9fa` / `#868e96` / `#9aa4af` / `#58a6ff` 这些主题色
- `photos.html` 与 `post.html` 共用这套片段；`post.html` 里对 `FileName == "photos"` 做了判断，
  因此即使 Gridea Pro 不按文件名匹配模板，`photos` 这篇文章也会走瀑布流渲染
- 离线预览脚本见仓库外层的 `preview-photos.py`（会生成带 EXIF 的示例照片并起本地服务）

## 使用

1. 在 Gridea Pro 应用内「主题」页选择本主题
2. 在「自定义」里按需调整参数
3. 预览、发布
